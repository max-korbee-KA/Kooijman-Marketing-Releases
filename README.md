# Kooijman Marketing

## Installeren

[**Download Kooijman Marketing voor Windows — Setup.exe**](https://github.com/max-korbee-KA/Kooijman-Marketing-Releases/releases/latest/download/KooijmanMarketing-Setup.exe)

Gebruik voor een nieuwe installatie deze officiële Setup en de interne installatiehandleiding. Open het gedownloade bestand, volg de stappen en meld je aan met je zakelijke Microsoft-account. Windows kan om beheerdersbevestiging vragen.

Je controleert updates in de app via **Instellingen → Updates → Controleren op updates**. Er wordt niets zonder jouw bevestiging geïnstalleerd.

### Staat de app al op je computer?

Laat eerst controleren of alle belangrijke wijzigingen zijn verzonden. Controleer daarna of de nieuwe Setup-app dezelfde gedeelde werkruimte opent. Verwijder de oude app pas na die controle; bewaar eventuele niet-verzonden gegevens. Oude installaties en gegevens worden niet automatisch verwijderd.

### Bestaande MSIX-installaties

[De bestaande MSIX-updatefeed](https://github.com/max-korbee-KA/Kooijman-Marketing-Releases/releases/latest/download/KooijmanMarketing.appinstaller) blijft voorlopig beschikbaar. Gebruik voor nieuwe installaties de Setup hierboven.

Deze repository bevat uitsluitend ondertekende downloads en installatie-informatie. Appbroncode, inloggegevens en gebruikersgegevens staan hier niet.
